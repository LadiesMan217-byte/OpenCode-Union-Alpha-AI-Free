## How to use
1. Download v1.18.31.
2. Extract `OpenCode-Union-Alpha-AI-Free.zip`.
3. Run the OpenCode desktop.
4. Pick Union Alpha (Zen) or `stealth/union-alpha` on OpenRouter.
5. Open a repo. Chat.
